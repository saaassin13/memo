# Step 17: "我的"页面功能设计

## 设计背景

这是一个本地安装到手机的个人生活管理 App，没有登录/云同步需求。"我的"页面需要展示**个人数据全景**，让用户看到自己在 App 里的生活轨迹。

## 二、功能模块详细设计

### 2.1 顶部用户卡片

| 元素 | 说明 |
|------|------|
| 头像 | 默认灰色人像图标，点击可从相册选择/拍照更换 |
| 问候语 | 根据时间动态：早上好/下午好/晚上好 |
| 使用天数 | 从首次打开 App 起计算，如「已使用第 47 天」|
| 背景 | 浅色渐变卡片，与底部导航风格统一 |

### 2.2 本周数据概览（核心展示区）

**三列数据卡片**，展示本周关键数据快照：

| 卡片 | 数据来源 | 显示内容 | 示例 |
|------|----------|----------|------|
| 待办完成 | Todo 表 | 本周完成数 / 总数 | 12/15 项 |
| 日记 | Diary 表 | 本周写了几篇 | 5 篇 |
| 体重趋势 | Weight 表 | 本周体重变化（带箭头颜色） | ↓3.2kg / ↑0.5kg |

**扩展可能**（第二行，折叠显示）：
| 卡片 | 数据来源 | 示例 |
|------|----------|------|
| 记账 | Expense 表 | 支出 ¥2,380 |
| 运动 | Weight 表 exercised | 4 次 |
| 备忘 | Memo 表 | 新增 6 条 |

### 2.3 数据统计入口列表

以卡片列表形式展示各功能模块的数据汇总，点击可跳转到对应功能：

| 条目 | 图标 | 左侧信息 | 右侧信息 | 跳转 |
|------|------|----------|----------|------|
| 备忘录 | 📝 | 备忘录 | 共 86 条 | 备忘录列表 |
| 目标 | 🎯 | 目标 | 3 个进行中 | 目标页 |
| 记账 | 💰 | 记账 | 本月 ¥2,380 | 记账页 |
| 体重 | ⚖️ | 体重 | 最近 65.2kg | 体重页 |
| 纪念日 | 🎂 | 纪念日 | 下次 3 天后 | 纪念日页 |
| 日记 | 📔 | 日记 | 共 23 篇 | 日记页 |

### 2.4 数据管理模块

| 功能 | 说明 | 交互 |
|------|------|------|
| 数据导出 | 将所有数据导出为 JSON 文件 | 点击后选择导出位置（分享/保存到文件）|
| 数据导入 | 从 JSON 文件导入恢复数据 | 选择文件，确认覆盖/合并 |
| 清除缓存 | 清除临时数据，不影响数据库 | 点击确认后清除 |
| 存储用量 | 显示数据库文件大小 | 只读展示 |

**导出格式**：单个 `.memo` 文件（实际是 JSON），包含所有表的数据，方便备份。

| 条目 | 说明 |

## 五、交互流程

```
用户进入"我的"页
    │
    ├── 查看本周概览数据（实时计算）
    │
    ├── 点击数据统计入口 → 跳转到对应功能页
    │
    ├── 点击数据导出 → 分享/保存 JSON 备份文件
    │
    ├── 点击数据导入 → 选择文件 → 确认 → 恢复数据
    │
    ├── 点击设置项 → 进入对应设置页
    │
    └── 点击头像 → 更换头像（相册/拍照）
```

## 八、注意事项

1. **数据实时性**：所有统计数据通过 Provider 流式监听，数据变化自动更新
2. **本地存储**：使用 SharedPreferences 存储首次打开日期（计算使用天数）和用户设置
3. **导出兼容性**：导出文件包含版本号，导入时校验版本兼容性
4. **性能考虑**：统计数据按需计算，不在页面初始化时全量查询
5. **空状态处理**：各统计数据在无数据时显示"暂无"而非 0
